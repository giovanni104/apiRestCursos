# NFC Secure Payment API

Proyecto Spring Boot con seguridad OWASP, cifrado AES, Docker, Swagger y pruebas Postman.

- `POST /api/payments/nfc`: registra pago
- `GET /api/payments`: consulta pagos

Despliegue rápido:
```bash
docker-compose up --build
```
Swagger en:
```
http://localhost:8080/swagger-ui.html
```
